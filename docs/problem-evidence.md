# Problem evidence

Recorded on 4 October 2026. Only evidence actually supplied or collected is reported here.

## Intended user and design hypothesis

Nivaran is intended for a consumer with a prepaid online order, an accepted return or a written
refund promise whose owed refund has not arrived. Their order and correspondence can be brought
into one source-linked case. Scattered evidence and uncertainty about a next step are the design
hypothesis; this repository does not yet establish how common they are or quantify the benefit.
Bank/UPI disputes and disputes over entitlement to a refund are outside this product's scope.
